## Decisions (Discovery)

- **2026-08-29 — Brand feeling.** Warm & trustworthy. Friendly, human, reassuring. Rounded, organic logo. Warm neutrals + single warm accent. Tone: "we help neighbors get their stuff back."
- **2026-08-29 — Type naming.** Use PRD verbatim — "Lost item" / "Found item" on primary surfaces (buttons, filters, badges, detail headers). No second-person shortcuts on these surfaces.
- **2026-08-29 — Dark mode.** First-class peer to light. Initial theme follows `prefers-color-scheme`. Toggle exposed in header / account menu. Choice persisted in `localStorage`. Logo ships in light + dark variants.
- **2026-08-29 — Reviewer Gate.** Rubric walker (Pass 1) + accessibility lens (WCAG 2.1 AA per PRD NFR). Generic / structure / adversarial lenses skipped at Finalize; trace covered inline.
- **2026-08-29 — UI system [ASSUMPTION].** Not specified in PRD; no shadcn / MUI / etc. implied. DESIGN.md provides token semantics; framework choice is an Architecture decision.
- **2026-08-29 — Form-factor [ASSUMPTION].** Web application only (PRD §5 non-goal). Responsive across desktop, tablet, mobile web.
